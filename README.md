# ものがたり紙芝居 v1.0.0

小説（2万5千字程度）を AI が場面に分け、漫画風の絵と Gemini TTS の朗読で「紙芝居」として上演・動画書き出しする Web アプリです。

## ファイル構成

```
monogatari-kamishibai/
├─ index.html        画面
├─ style.css         デザイン
├─ app.js            画面の動き（認証・編集・生成・上演・録画）
├─ config.js         GAS URL などの設定
└─ gas/
   ├─ Code.gs        GAS バックエンド（会員・Gemini・Drive）
   └─ appsscript.json
```

## データの流れ

| 役割 | 保存先 |
|---|---|
| 会員情報（ハッシュ化パスワード・同意日時） | スプレッドシート「ものがたり紙芝居_会員」/ Users シート |
| 作品（本文・場面・人物） | Drive「ものがたり紙芝居_data / u_xxx / p_作品ID / project.json」 |
| 場面の絵・三面図・背景参考・朗読 WAV | 同じ作品フォルダ |

## セットアップ手順

### 1. GAS プロジェクトを作る
1. https://script.google.com で「新しいプロジェクト」を作成し、名前を `monogatari-kamishibai` にします。
2. `Code.gs` の中身を `gas/Code.gs` で置き換えます。
3. 「プロジェクトの設定」→「appsscript.json をエディタで表示する」をオンにし、`gas/appsscript.json` で置き換えます。
   （clasp を使う場合は `gas/` フォルダで `clasp create` → `clasp push`）

### 2. API キーとモデルを設定する
「プロジェクトの設定」→「スクリプト プロパティ」に追加します。

| プロパティ | 値 | 必須 |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio で発行したキー | 必須 |
| `APP_URL` | 公開ページの URL（例 `https://kenken6291.github.io/monogatari-kamishibai/`）。仮パスワードのメールに載ります | 任意 |
| `TEXT_MODEL` | 場面解析用（既定 `gemini-2.5-flash`） | 任意 |
| `IMAGE_MODEL` | 画像生成用（既定 `gemini-2.5-flash-image`） | 任意 |
| `TTS_MODEL` | 朗読用（既定 `gemini-2.5-flash-preview-tts`） | 任意 |

新しいモデルに切り替えるときは、コードを触らずにこのプロパティだけ書き換えれば反映されます。

### 3. 初回セットアップを実行する
エディタ上部の関数選択で `setup` を選んで「実行」→ 権限を承認します。
Drive に `ものがたり紙芝居_data` フォルダと会員スプレッドシートが作られ、ID がスクリプトプロパティ（`ROOT_FOLDER_ID` / `SPREADSHEET_ID`）に自動で入ります。

### 4. ウェブアプリとしてデプロイする
「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**

発行された `https://script.google.com/macros/s/…/exec` をコピーします。
コードを更新したら「デプロイを管理」→ 鉛筆アイコン →「新バージョン」で同じ URL のまま更新できます。

### 5. フロントエンドを GitHub Pages に公開する
1. リポジトリ `monogatari-kamishibai` を作り、`index.html` `style.css` `app.js` `config.js` を置きます（`gas/` は入れても動作に影響しません）。
2. `config.js` の `GAS_URL` に手順4の URL を入れます。
3. Settings → Pages → Branch `main` / root で公開します。
4. 画面右上の「設定」からも GAS URL を上書きできます（その端末のブラウザに保存）。

### 6. 動作確認
1. 「新規登録」→ 4つの同意にチェック → 仮パスワードのメールが届く
2. 仮パスワードでログイン → パスワード変更画面が出る
3. 本文を貼る →「AIで場面に分ける」→「絵を一括生成」→「朗読を一括生成」→「上演する」

## 仕様メモ

- **場面数の算出**：本文を段落番号つきで Gemini に渡し、およそ700字に1枚を目安に、山場は細かく・説明部分はまとめるよう指示。返ってきた段落範囲はサーバー側で抜け・重なりを補正します。
- **画像サイズ**：横長 16:9 / 縦長 9:16 / 正方形 1:1。生成時に `imageConfig.aspectRatio` で指定し、上演キャンバスも同じ比率になります。
- **人物の一貫性**：人物ごとに特徴文と三面図（アップロードまたはAI生成）を保持し、その人物が出る場面の生成時に三面図を参照画像として最大3人分添付します。
- **Google Earth Studio 連携**：Earth Studio で書き出した風景の静止画を、場面ごとに「背景参考を入れる」で添付すると、その地形・構図を参考に漫画風の背景で描きます。
- **パン・スライド演出**：ゆっくり寄る／引く、上下左右へのパン、スライドで登場、動かさないの8種。AIが場面ごとに提案し、対応表で変更できます。場面の切り替えは0.8秒のクロスフェード。
- **朗読の指示語対策**：TTS には指示文を一切付けず本文だけを渡します。さらに青空文庫の注記・ルビ・記号と、冒頭の「〜を朗読してください」等の行を除去します（台詞中の同じ言葉は残します）。長い場面は600字ごとに分けて生成し、0.25秒の間を挟んで1つの WAV に結合します。
- **音声入力**：`continuous` で認識し、ブラウザが途中で切っても自動で再開します。`config.js` の `SPEECH_SILENCE_MS`（既定8秒）無音が続いたときだけ終了します。
- **動画書き出し**：上演中のキャンバスと音声を MediaRecorder で録画し WebM で保存します（Chrome 推奨。録画中はタブを表示したままにしてください）。
- **会員**：同意4項目必須、仮パスワードのメール通知、初回強制変更、再発行、表示/非表示切替、5回失敗で15分ロック。セッションは6時間。

## 制限と注意

- GAS の1回の実行は最大6分です。朗読は1場面ずつ生成するため通常は収まりますが、1場面が極端に長い場合は「場面に分ける」をやり直して細かくしてください。
- 朗読 WAV は 1分あたり約2.9MB です。上演前に全場面を読み込むため、30分程度の作品では読み込みに時間がかかります。
- 画像生成がブロックされた場合は「描写を編集」で表現を穏やかにして作り直してください。
- 入力する小説は、権利を持つもの、または著作権の保護期間が終わったものに限ってください。
